TERMUX • ANDROID • OPEN SOURCE

apksign

Công cụ quản lý chữ ký Android release trên Termux. Tạo keystore RSA-4096, xem certificate, xuất Base64 cho GitHub Actions, kiểm tra APK và sao lưu signing key.

⬇ Tải ZIP GitHub Repository Releases

Tính năng

🔐 RSA-4096

Tạo Android release keystore dùng cho quá trình phát hành ứng dụng.

🧾 SHA-256

Xem certificate và fingerprint để kiểm tra signing identity.

📦 GitHub Actions

Xuất keystore Base64 và dùng bộ Secret chuẩn hóa.

✅ Verify APK

Kiểm tra chữ ký APK bằng Android apksigner.

💾 Backup

Tạo bản sao lưu keystore để tránh mất signing key.

🛡️ An toàn

Không ghi đè keystore đang tồn tại và không đưa private key vào repo.

Cài đặt nhanh

pkg update -y
pkg install git -y
git clone https://github.com/khahdihdz/apksign.git
cd apksign
chmod +x apksign
./apksign

GitHub Secrets

Bộ Secret chuẩn dùng cho Android repositories:

ANDROID_SIGNING_KEYSTORE_BASE64
ANDROID_SIGNING_STORE_PASSWORD
ANDROID_SIGNING_KEY_ALIAS
ANDROID_SIGNING_KEY_PASSWORD

Giữ an toàn signing key

Không commit file .jks, Base64 keystore hoặc mật khẩu vào repository public. Để cập nhật ứng dụng Android, hãy giữ nguyên application ID và release signing key của ứng dụng đã phát hành.
