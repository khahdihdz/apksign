Cài đặt nhanh trên Termux

Mở Termux và chạy lệnh sau để cài đặt hoặc cập nhật:

curl -fsSL https://raw.githubusercontent.com/khahdihdz/apksign/main/install.sh | sh
apksign

Cập nhật về phiên bản mới nhất:

apksign --update

Dữ liệu signing được giữ trong ~/.apksign/ khi cập nhật công cụ.

Thiết lập lần đầu

Khi mở apksign lần đầu, bạn được chọn cách chuẩn bị môi trường. Chương trình không cài gói nếu chưa có lựa chọn xác nhận và không tự tạo keystore hoặc thay đổi tài khoản GitHub/Google.

Chọn cách cài đặt

  1. 1 · Cài tất cả: OpenJDK 17, Coreutils, GitHub CLI, rclone, OpenSSL và tar.
  2. 2 · Chọn nhóm: cài nhóm keystore; sau đó tùy chọn nhóm GitHub CLI và Google Drive.
  3. 3 · Bỏ qua: vào menu chính và có thể chạy mục 11 để cài bổ sung sau.

Bạn có thể chọn không cài một nhóm gói và bổ sung sau bằng mục 11 · Kiểm tra / cài đặt gói cần thiết. Termux:API là tùy chọn riêng để nhận thông báo Android.

Trình tự khởi tạo đề xuất

  1. Nếu đang có keystore dùng để phát hành ứng dụng, tiếp tục sử dụng key đó; không tạo key mới.
  2. Nếu chưa có keystore, chọn mục 2 để tạo release key.
  3. Chọn mục 9 để xác minh keystore và đồng bộ bốn GitHub Secrets.
  4. Cấu hình rclone remote gdrive, sau đó dùng mục 10 → 1 để sao lưu.

Không gửi keystore, mật khẩu, GitHub token hoặc OAuth Client Secret cho người khác. Mọi thao tác cài đặt gói đều hỏi xác nhận trước.

Thiết lập Google Drive Backup

Chỉ cần cấu hình rclone một lần trên thiết bị. Cài các gói cần thiết:

pkg update -y
pkg install rclone openssl tar -y
rclone config
  1. Tạo remote tên gdrive, chọn backend Google Drive.
  2. Nếu dùng OAuth Client riêng, tạo OAuth Client ID loại Desktop app trong Google Cloud Console và bật Google Drive API.
  3. Chọn scope drive; để trống service_account_file; chọn n cho Advanced config và Shared Drive nếu dùng My Drive.
  4. Chọn y để xác thực qua trình duyệt, đăng nhập Google và cấp quyền.
  5. Kiểm tra remote bằng rclone lsd gdrive:.
  6. Chạy apksign → mục 9 để xác minh và lưu bộ signing. Sau đó chọn mục 10 → 1 để backup.

Bản backup được tải lên gdrive:apksign-backups/ với tên dạng apksign-backup-YYYYMMDD-HHMMSS.tar.gz.enc.

Archive dùng AES-256-CBC + PBKDF2 (300.000 vòng, SHA-256). Mật khẩu giải mã là signing store password. Hãy giữ mật khẩu và một bản backup ngoại tuyến an toàn.

Khôi phục bản backup

  1. Mở apksign → mục 10 → chọn 2. Khôi phục.
  2. Chọn tên archive trên Google Drive và nhập signing store password đã dùng để mã hóa.
  3. Công cụ tải xuống, giải mã và kiểm tra archive trước khi khôi phục.
  4. Keystore/Base64 được khôi phục vào ~/.apksign/. Nếu keystore hiện tại tồn tại, công cụ tạo bản sao dự phòng trước khi thay thế.

Restore không tự cập nhật GitHub Secrets. File secrets khôi phục được lưu tại ~/.apksign/backup-secrets.env; không chia sẻ hoặc commit file này.

Bộ GitHub Actions Secrets

Bốn tên secret được dùng thống nhất giữa các Android repository:

ANDROID_SIGNING_KEYSTORE_BASE64
ANDROID_SIGNING_STORE_PASSWORD
ANDROID_SIGNING_KEY_ALIAS
ANDROID_SIGNING_KEY_PASSWORD

Workflow đồng bộ trung tâm có thể phát hiện Android repository và đồng bộ secrets theo cấu hình của repository apksign.

Bảo mật signing key

  • Không commit keystore, Base64, mật khẩu, credentials hoặc archive backup lên repository.
  • Không tạo keystore mới cho ứng dụng đã phát hành; giữ nguyên Application ID và release signing key.
  • Bảo vệ thư mục ~/.apksign/credentials/ và mật khẩu signing.
  • Giữ ít nhất một bản sao lưu ngoại tuyến ở nơi an toàn.
